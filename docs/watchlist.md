# Как добавлять токены в сканер

Сканер (`scripts/scan.js`) по умолчанию проверяет список `WATCHLIST`, то есть ваше избранное на BingX. Если вы добавили или удалили токены в избранном на бирже, обновите этот список вручную: сканер не синхронизируется с биржей, потому что API BingX не отдаёт избранное.

## 1. Узнайте точное имя контракта

Откройте контракт на BingX. Имя есть в адресе страницы: `https://bingx.com/en/perpetual/SOL-USDT`, где `SOL-USDT` — нужное имя.

В список пишется **только базовая часть без `-USDT`**:

| На бирже | В `WATCHLIST` |
|---|---|
| `SOL-USDT` | `SOL` |
| `1000PEPE-USDT` | `1000PEPE` |
| `1000BONK-USDT` | `1000BONK` |

У мелких мемкоинов перед именем часто стоит множитель (`1000`, `1000000`). Пишите его точно так же, как на бирже: `PEPE` и `1000PEPE` — это разные контракты.

Проверить, что контракт существует, можно одной командой:

```bash
npm run scan -- НОВЫЙТОКЕН
```

Если в строке токена появилась ошибка (`error: ...`), значит, имя неверное или такого контракта на BingX нет.

## 2. Добавьте токен в список

Откройте `scripts/scan.js` и найдите в начале файла:

```js
const WATCHLIST = `BTC ETH SOL ZEC XRP 1000PEPE HYPE ...
...
MORPHO MYX ARC MNT FLOKI RATS ANSEM`;
```

Допишите тикер **через пробел** в любое место внутри обратных кавычек `` ` ``. Переносы строк тоже допустимы. Регистр не важен. Чтобы убрать токен, просто удалите его из списка.

Пример: добавить `NEAR` и `WLD`:

```js
MORPHO MYX ARC MNT FLOKI RATS ANSEM NEAR WLD`;
```

Порядок в списке определяет порядок строк в таблице.

## 3. Проверьте

```bash
npm run scan
```

В конце таблицы появятся новые токены, без строк `error`.

## 4. Сохраните изменения в git и отправьте в GitHub

```bash
git add scripts/scan.js
```
```bash
git commit -m "Сканер: добавлены NEAR и WLD"
```
```bash
git push
```

## Разовая проверка без изменения списка

Если токен нужно посмотреть один раз, файл менять не обязательно. Перечислите тикеры после `--`:

```bash
npm run scan -- NEAR WLD BTC
```

Принимаются все варианты записи: `NEAR`, `NEARUSDT`, `NEAR-USDT`, `near/usdt`.
